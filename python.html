🖥️ PC Info Tool Checker

Voor dit project heb ik een Python-applicatie ontwikkeld die realtime informatie over de prestaties van een computer weergeeft. De applicatie monitort onder andere het gebruik van de CPU, RAM, en opslag en toont deze gegevens overzichtelijk in percentages. Met behulp van deze tool kan snel worden gecontroleerd hoe zwaar een systeem wordt belast en welke onderdelen de meeste resources gebruiken. Dit project heeft mij meer inzicht gegeven in het uitlezen en verwerken van systeeminformatie met Python. (er is ook een knop voor een ds emulator te hebben dit heb ik gedaaan om met subprocess te werken en een ander programma te openen)

🐦 Flappy Bird (Pygame)

Naast de PC Info Tool heb ik ook een eigen versie van Flappy Bird ontwikkeld met behulp van de Pygame-bibliotheek. In dit spel bestuurt de speler een vogel die tussen obstakels door moet vliegen zonder deze te raken. Tijdens de ontwikkeling heb ik gewerkt met functies zoals beweging, botsingsdetectie, scoreberekening en gebruikersinvoer. Door dit project heb ik praktische ervaring opgedaan met de basisprincipes van gameontwikkeling in Python en het werken met de Pygame-engine.
